# @aphel-crm/sdk

TypeScript client for the Aphel REST API (`/api/v1`). The types come from the OpenAPI document (`back/openapi.json`) generated by the backend: paths, parameters, bodies and responses are checked by the compiler.

- ESM, no runtime dependencies (uses the global `fetch`; Node 18+, browsers, Deno, Bun).
- API token in the `Authorization: Bearer aphel_<prefix>_<secret>` header.
- API errors become `AphelApiError` (`status`, `code`, `message`, `details`, `fieldErrors`, `retryAfter`).
- Pagination (`paginate`, `listAll`), `filter[field][op]`, `include=`, `sort=`, `If-Match` and `Idempotency-Key`.

## Installation

The package lives in the monorepo at `sdk/typescript` and is not yet published to npm.

```bash
cd sdk/typescript
npm ci
npm run generate   # generates src/schema.ts from ../../back/openapi.json
npm run build      # compiles to dist/
npm pack           # produces aphel-crm-sdk-0.1.0.tgz (prepack runs generate + build)
```

In your project: `npm install /path/to/aphel-crm-sdk-0.1.0.tgz` or, in an npm workspace, `"@aphel-crm/sdk": "file:../aphel/sdk/typescript"`.

### Generating the types from another source

`src/schema.ts` is generated and is not kept in git. By default it comes from `back/openapi.json`; to generate it from a running instance (for example one with different extensions):

```bash
npm run generate -- https://crm.yourcompany.com/api/openapi.json
APHEL_OPENAPI_URL=http://127.0.0.1:3001/api/openapi.json npm run generate
npm run generate -- ./openapi.json
```

## Usage

```ts
import { createAphelClient, isAphelApiError, unwrap } from '@aphel-crm/sdk'

const aphel = createAphelClient({
  baseUrl: 'https://crm.yourcompany.com',
  token: process.env.APHEL_TOKEN,
  timeoutMs: 15_000,
})

const organization = unwrap(await aphel.get('/api/v1/organization'))

const page = await aphel.get('/api/v1/contacts', {
  query: { page: 1, per_page: 50 },
  filter: { email: { contains: '@acme.com.br' }, created_at: { gte: '2026-01-01' } },
  sort: ['-created_at'],
})
console.log(page.meta.total, page.data.map((contact) => contact.email))

const contact = unwrap(
  await aphel.post('/api/v1/contacts', {
    body: { first_name: 'Bruna', last_name: 'Lima', email: 'bruna@acme.com.br' },
    idempotencyKey: true,
  }),
)

try {
  await aphel.patch('/api/v1/contacts/{contact_id}', {
    path: { contact_id: contact.id },
    body: { job_title: 'Sales director' },
    ifMatch: contact.updated_at,
  })
} catch (error) {
  if (isAphelApiError(error, 'version_conflict')) {
    console.log('the contact changed since it was read; reload it and reapply')
  } else {
    throw error
  }
}

for await (const deal of aphel.paginate('/api/v1/deals', { filter: { status: 'open' } })) {
  console.log(deal.title, deal.amount, deal.currency)
}
```

### Quick reference

| Feature | How |
| --- | --- |
| Calls | `get`, `post`, `put`, `patch`, `delete` (OpenAPI path, e.g. `'/api/v1/deals/{deal_id}'`) or `request(method, path, options)` |
| Full response | `send(method, path, options)` returns `{ status, headers, body, rateLimit, replayed }` |
| Path parameters | `path: { deal_id: '...' }` |
| Query | `query: { page, per_page, search, ... }` |
| Simple filter | `filter: { status: 'open', amount: { gte: 1000 }, stage_id: { in: ['a', 'b'] }, email: { is_empty: true } }` becomes `filter[status][eq]=open&filter[amount][gte]=1000&...` (`buildFilterQuery`) |
| Tree filter | `filterTree: { op: 'or', conditions: [...] }` becomes `filter=<JSON>` |
| Relationships | `include: ['company', 'owner']` |
| Sorting | `sort: ['-amount', 'title']` |
| Concurrency | `ifMatch: record.updated_at` (409 `version_conflict` if it changed) |
| Idempotency | `idempotencyKey: 'my-key'` or `true` (generates a UUID) on `POST` |
| Pagination | `paginate(path, options, { perPage, startPage, maxPages })` and `listAll(...)` |
| Errors | `AphelApiError` / `isAphelApiError(error, code?)`; codes in `docs/api/errors.md` |
| Types | `Schemas['ContactResponse']`, `paths`, `components`, `operations` |

See also [`docs/api/sdk.md`](../../docs/api/sdk.md).
