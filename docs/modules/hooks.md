# Hook catalog

Generated by `aphel modules hooks --markdown` from the modules in this build. Do not edit by hand: run `cargo run -q -p aphel -- modules hooks --markdown > ../docs/modules/hooks.md` in `back/`.

Usage: `veto` and `action` are registered with `app.on::<Hook, _>(priority, handler)` (an error from a `veto` cancels the operation); `filter` with `app.filter::<Hook, _>(priority, handler)`, which returns the changed value. Lower priority runs first.
