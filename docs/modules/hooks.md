# Hook catalog

Generated by `aphel catalog --markdown hooks` from the plugins in this build. Do not edit by hand: run `cargo run -q -p aphel -- catalog --markdown hooks > ../docs/modules/hooks.md` in `back/` (or `make catalog-docs`).

Usage: `veto` and `action` are registered with `app.on(Hook, priority, handler)` (an error from a `veto` cancels the operation); `filter` with `app.filter(Hook, priority, handler)`, which returns the changed value. Lower priority runs first.
