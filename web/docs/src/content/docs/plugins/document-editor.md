---
title: Document editor
description: "How a plugin lets the host edit its documents: the DocumentKind, the flow body, the checklist and the publish panel."
---

The host web SDK (`@aphel/web-sdk`) ships the editor used by the native site pages and by the Blog plugin. A plugin does not write an editor: it describes its document with a `DocumentKind` and mounts `DocumentEditorPage` under a `DocumentKindContext`.

```tsx
import { DocumentEditorPage, DocumentKindContext, FlowBody, type DocumentKind } from '@aphel/web-sdk'

const kind: DocumentKind = {
  recordType: 'blog.post',
  blocks: 'body',
  listPath: () => '/blog/posts',
  editPath: (id) => `/blog/posts/${id}`,
  createPermission: 'blog.post.create',
  updatePermission: 'blog.post.update',
  deletePermission: 'blog.post.delete',
  publishPermission: 'blog.publish',
  structure: false,
  get, update, remove,
  path: (record) => `/${blogPath}/${record.slug}`,
  previewFields: { title: 'draft_title', body: 'draft_body' },
  Settings: PostSettingsDialog,
}

<DocumentKindContext.Provider value={kind}><DocumentEditorPage /></DocumentKindContext.Provider>
```

The record type needs the working copy and projection fields generated by `published_by = "publication"` (`draft_title`, `draft_<blocks>`) and the editor saves with the version check (`_expected_updated_at`).

| Key | Meaning |
| --- | --- |
| `Body` | Replaces the list of blocks. `FlowBody` edits the document as one page of text with a slash menu, image paste and drop, focus mode and an optional live preview; it converts to and from the blocks the server validates. |
| `untitled` | Title saved while the person has not typed one. The flow body shows an empty title instead. |
| `checklist(input)` | Items shown in the publish panel before publishing: `{ key, ok, required?, values? }`. Required items block. Labels come from the kind's texts under `checklist.<key>`. |
| `snippet(input)` | `{ description, image? }` shown as the search result and social card in the publish panel. |
| `texts` | `{ namespace, scope }`: texts looked up in the plugin's own namespace before the host's `editorial` namespace. |
| `duplicate`, `structure` | Duplicate action and the home-page and menu actions of the site structure. |

With a `checklist` the *Publish* button opens the panel (checklist, search preview, publish now or schedule, and share links once live). Without it, the button publishes at once.
